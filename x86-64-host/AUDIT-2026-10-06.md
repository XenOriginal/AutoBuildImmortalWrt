## 三、核验：到位 / 未到位（附实证）

### ✅ D 串口控制台 —— 到位

从 `run 37102181389` 产物 `immortalwrt-x86-64-generic-squashfs-combined-efi.img.gz`
解出 rootfs，`/etc/inittab` 实为：

```
::sysinit:/etc/init.d/rcS S boot
::shutdown:/etc/init.d/rcS K shutdown
ttyS4::askfirst:/usr/libexec/login.sh
hvc0::askfirst:/usr/libexec/login.sh
tty1::askfirst:/usr/libexec/login.sh
```

内核侧符号在闸门 1 / 闸门 2 均全绿。

### ❌ B QAT —— 只编译未安装（核心目标未达成）

**根因**：`build-source.sh` 把三个 QAT 包写成 `=m`：

```
CONFIG_PACKAGE_kmod-crypto-qat-common=m
CONFIG_PACKAGE_kmod-crypto-qat-dh895xcc=m
CONFIG_PACKAGE_qat-firmware-dh895xcc=m
```

而 OpenWrt 的 rootfs 安装戳**只对 `=y` 生成**（`include/package-pack.mk` 第 351 行）：

```make
ifeq ($(CONFIG_PACKAGE_$(1)),y)
  compile: $(PKG_INSTALL_STAMP).$(1)
endif
```

`=m` 只把 `.apk` 编出来丢进 `bin/targets/x86/64/packages/`，**不装进 rootfs**。

**实证**（权威清单 `immortalwrt-x86-64-1024.manifest`，`apk list --manifest` 生成，398 个包）：

| 包 | `.config` 取值 | 在固件清单中 |
|---|---|---|
| `kmod-crypto-qat-common` | `m` | ❌ 无 |
| `kmod-crypto-qat-dh895xcc` | `m` | ❌ 无 |
| `qat-firmware-dh895xcc` | `m` | ❌ 无 |
| `kmod-crypto-rng` | `y` | ✅ 有 |
| `kmod-mlx5-core` / `kmod-i40e` / `kmod-tcp-bbr` / `kmod-zram` | `y` | ✅ 有 |

rootfs 内 `/lib/modules/6.12.108/` 共 **244 个 `.ko`，无一个 qat**；
`/lib/firmware/` 下**没有** `qat_895xcc.bin`。

⇒ **该工作流名为 "QAT enabled"，但产出的固件刷进机器后并没有 QAT。**
这解释了此前在路由器上实测到"QAT 模块 0、包 0"的现象。

### ❌ C 宿主机调优 —— 完全未进入固件

**根因**：工作流把调优文件组装到 `$GITHUB_WORKSPACE/files/`，只读挂载为
`/host-files`；但 OpenWrt 只读**源码树根**下的 `files/`（`include/image.mk` 第 423 行）：

```make
$(call prepare_rootfs,$(mkfs_cur_target_dir),$(TOPDIR)/files)
```

源码树在 `/work/immortalwrt`，故 `$(TOPDIR)/files = /work/immortalwrt/files`。
`build-source.sh` **从未引用 `/host-files`**（`git log -S host-files` 全历史为空），
也从未复制到 `$SRC_DIR/files` —— 覆盖层被静默丢弃。

对照：ImageBuilder 工作流是**正确**写法（`-v .../files:/home/build/immortalwrt/files`），
所以缺陷只存在于源码编译路线，属于切换到源码编译时的新增回归。

**实证**（同一份产物）：

| 期望存在 | 实际 |
|---|---|
| `/etc/sysctl.conf`（含 `tcp_congestion_control=bbr`） | ❌ 仅 154 字节出厂占位文件 |
| `/etc/init.d/host-zram` | ❌ 不存在 |
| `/etc/init.d/hsuart-console-detect` | ❌ 不存在 |
| `/etc/modules.d/40-qat` | ❌ 不存在 |
| `/etc/uci-defaults/99-host.sh` | ❌ 不存在 |
| `/etc/config/custom_router_ip.txt` | ❌ 不存在 |
